# Vishnu Das CP — portfolio

An interview-focused React portfolio based on `Vishnu_Das_CP_Resume_5.pdf`.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To check the production bundle, run `npm run build`.

The résumé download is stored in `public/`. Update the content arrays in `src/App.jsx` when experience, projects, or skills change.
